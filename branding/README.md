# Super Lan-Cache icon

Original vector mark, licensed under this project's MIT license. `icon.svg` is the editable source; `icon.png` is the 512 × 512 TrueNAS/catalog asset. No upstream Pi-hole, LanCache or TrueNAS logo is used.

Catalog icon URL: https://raw.githubusercontent.com/HDR-Performance/super-lan-cache/main/branding/icon.png

TrueNAS Community submissions supply the icon to reviewers for CDN hosting. A custom YAML app may still show the generic TrueNAS icon: Compose has no supported custom-icon field. See the installation guide.
